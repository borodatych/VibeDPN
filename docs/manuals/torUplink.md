# БЕСПЛАТНЫЙ ВЫХОД ЧЕРЕЗ TOR

Как открыть через коробку заблокированные сайты и Telegram, не заводя ни аккаунтов, ни криптовалюты, ни своей VPS
Коробка подключается к сети Tor через мосты Snowflake: они проходят там, где сам Tor заблокирован
Всё основное делается в панели коробки, команды — под каждым шагом

## Что это даёт и чего не даёт

Работает: сайты и Telegram — всё, что ходит по TCP
Не работает: звонки, игры, прочий UDP
Браузеры сами переходят с QUIC на обычный HTTPS
Скорость через Snowflake — около 1 Мбит/с: страницы и сообщения да, видео нет
Часть сайтов показывает выходным узлам Tor капчу

Если выход упал или ещё не подключился, трафик через него стоит, а не уходит напрямую

---

## 1. Включить выход

**Шаг 1.** Откройте страницу «Выходы», карточку «Бесплатный выход через Tor», и нажмите «Включить»

**Шаг 2.** Дождитесь строки «Применено» и подождите ещё минуту-две: коробка подключается к Tor
Статус в карточке сменится на «включён»

**Проверка:** на странице «Статус» у выхода `TOR` шлюз «отвечает»

**То же командами.**

```bash
sudo vibedpn tor enable
sudo vibedpn up
```

Контейнер `tor` должен быть в состоянии `healthy`:

```bash
sudo vibedpn status
```

---

## 2. Отправить через него сайты

Умный режим: через Tor идут только перечисленные сайты, остальное напрямую

**Шаг 1.** Откройте страницу «Правила»
Введите сайт в поле «Сайт», выберите канал «Через Tor» и нажмите «Добавить правило»
Повторите для каждого сайта

**Шаг 2.** Включите умный режим
В панели кнопки умного режима нет: в карточке «Маршрутизация» на «Статусе» только «Выключен — LAN напрямую» и «Полный — через аплинк»
Умный режим включается командой `sudo vibedpn mode smart`

Правило действует и на поддомены: `rutracker.org` покрывает `www.rutracker.org`

**Проверка:** сайт стоит в таблице правил с каналом «Tor»

**То же командами.**

```bash
sudo vibedpn rule add rutracker.org tor
sudo vibedpn rule add lostfilm.today tor
sudo vibedpn mode smart
```

### Все известные заблокированные сайты сразу

Вместо сайтов по одному можно отдать Tor готовый общественный список заблокированных в России доменов
Коробка скачивает его сразу, обновляет раз в сутки и при недоступном адресе работает по сохранённой копии

**Шаг 1.** На странице «Правила» найдите блок «Списки доменов»
В поле «URL списка» вставьте `https://community.antifilter.download/list/domains.lst`, выберите канал «Через Tor» и нажмите «Добавить список»

**Проверка:** в таблице списков в колонке «Копия» появится число доменов

**То же командами.**

```bash
sudo vibedpn lists add https://community.antifilter.download/list/domains.lst tor
sudo vibedpn lists show
```

На 17.09.2026 в нём 485 доменов: rutracker, lostfilm с зеркалами, nnmclub, rutor, kinozal, 4pda, instagram и другие
Список открывается с российского адреса; из-за границы сервер не отвечает — проверять с самой коробки
Правило сайта сильнее списка: правило с каналом «Напрямую» (`sudo vibedpn rule add <сайт> direct`) оставит сайт из списка напрямую

## 3. Telegram

Приложение Telegram соединяется с адресами своих дата-центров, а не по именам, поэтому ему нужны правила по сетям
Официальный список сетей: https://core.telegram.org/resources/cidr.txt — берутся строки IPv4

**Шаг 1.** На странице «Правила» найдите блок «Сети адресов»
Выберите канал «Через Tor» и нажмите «Добавить сети Telegram»
Отдельную сеть можно добавить полем «Сеть a.b.c.d/nn» и кнопкой «Добавить сеть»

**Шаг 2.** В блоке правил сайтов добавьте `telegram.org`, `t.me` и `telegra.ph` с каналом «Через Tor», как в разделе 2

**Проверка:** под кнопкой строка «Сети Telegram: добавлено …», сети стоят в таблице с каналом Tor

**То же командами.**

```bash
for net in 91.108.56.0/22 91.108.4.0/22 91.108.8.0/22 91.108.16.0/22 91.108.12.0/22 \
  149.154.160.0/20 91.105.192.0/23 91.108.20.0/22 185.76.151.0/24; do
  sudo vibedpn net add "$net" tor
done
sudo vibedpn rule add telegram.org tor
sudo vibedpn rule add t.me tor
sudo vibedpn rule add telegra.ph tor
```

Список сетей на 17.09.2026; перед вводом сверить с официальным файлом

## 4. Весь трафик через Tor

**Шаг 1.** На странице «Статус» в карточке «Маршрутизация» в строке «Аплинк» нажмите `TOR`
Строка «Аплинк» видна, когда включено больше одного выхода

**Шаг 2.** В строке «Режим» нажмите «Полный — через аплинк» и подтвердите

**Шаг 3.** Российские сервисы часто не пускают зарубежные адреса
Их оставьте напрямую: на странице «Правила» добавьте сайт с каналом «Напрямую»

**Шаг 4.** Одно устройство целиком через Tor, остальные как были:
Страница «Устройства», в колонке «Политика» у нужного устройства выберите «Через Tor»

**Проверка:** в карточке «Маршрутизация» выделены «Полный — через аплинк» и `TOR`

**То же командами.**

```bash
sudo vibedpn upstream tor
sudo vibedpn mode full
sudo vibedpn rule add gosuslugi.ru direct
sudo vibedpn device set <MAC> tor
```

## 5. Проверить

**Шаг 1.** На странице «Статус» у выхода `TOR` шлюз в состоянии «отвечает»

**Шаг 2.** На «Статусе» в карточке «Проверка коробки» нажмите «Проверить с адресами выходов» и подтвердите
В строке выхода tor — адрес узла Tor, не ваш

**Шаг 3.** С устройства LAN откройте сайт, показывающий ваш IP, для сайта из правил: адрес должен смениться

Сразу после `vibedpn up` шлюз заново соединяется с мостами, и первая проверка может не успеть: повторите её через минуту

**То же командами.**

```bash
sudo vibedpn doctor --network
```

В строке `exit tor` — адрес узла Tor, не ваш

## 6. Если не подключается

**Шаг 1.** На странице «Выходы» в карточке «Журналы» выберите `tor` и нажмите «Показать»

**То же командами.**

```bash
sudo vibedpn logs tor
```

**`Bootstrapped` стоит на месте.** Мосты не проходят
Карточка Tor на «Выходах» показывает текущие мосты строкой «Мосты: …», но менять их в панели нельзя — только в `config.yaml`
Встроенные мосты меняются с выпусками Tor Browser: свежие — в `pt_config.json` проекта Tor Browser, раздел `bridges.snowflake`
Адрес файла:
https://gitlab.torproject.org/tpo/applications/tor-browser-build/-/raw/main/projects/tor-expert-bundle/pt_config.json
Свои строки мостов кладутся в `config.yaml`, после правки — `sudo vibedpn up`:

```yaml
upstreams:
  tor:
    enabled: true
    bridges:
      - "snowflake 192.0.2.3:80 ..."
```

Поддерживаются транспорты `snowflake`, `obfs4` и `meek_lite`
Встроенные obfs4-мосты Tor Browser у Ростелекома в сентябре 2026 не проходили

**Сайт открывается медленно или с капчей.** Это особенность выходных узлов Tor, а не коробки

---

## 7. Выключить

**Шаг 1.** Сначала переведите на другой канал правила сайтов, сети и политики устройств с каналом Tor
Иначе коробка откажется выключать выход, через который идёт трафик

**Шаг 2.** На странице «Выходы» в карточке «Бесплатный выход через Tor» нажмите «Выключить» и подтвердите

**То же командами.**

```bash
sudo vibedpn tor disable
sudo vibedpn up
```
