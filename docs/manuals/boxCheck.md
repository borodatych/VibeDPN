# ПРОВЕРКА КОРОБКИ

Как узнать, всё ли с коробкой в порядке: в панели, по расписанию и командой.

---

## 1. Что проверяется

То, что видит `vibedpn doctor`:
- конфиг, секреты роли, модули ядра для туннелей и файрвола, IP-forwarding
- кто занял нужные порты, жив ли Docker, здоровы ли службы
- роутер LAN, kill-switch, выходы, файрвол VPS, сервер доступа, Telegram-бот

У каждой проверки вердикт — ok, предупреждение или ошибка, — пояснение и подсказка, что сделать.
Ничего не чинится молча: проверка только смотрит.

Пояснения и подсказки `doctor` пишет по-английски — так же, как ошибки ядра в остальной панели.

---

## 2. В панели

Страница «Статус», карточка «Проверка коробки».

Сверху — когда была последняя проверка и сколько каких вердиктов.
Ниже — ошибки и предупреждения с пояснениями; проверки без замечаний свёрнуты, их показывает кнопка.

Кнопки:
- **«Проверить»** — проверка, не выходя из коробки в интернет
- **«Проверить с адресами выходов»** — ещё и спрашивает у api.ipify.org внешний адрес коробки и адрес через каждый выход. Так видно, что трафик выхода действительно идёт через туннель. Сервис увидит каждый из этих адресов, поэтому кнопка спрашивает подтверждение

Проверку делает хост коробки, а не панель: Docker, порты, модули ядра видны только оттуда.
Обычно она занимает секунды, с адресами выходов — до минуты.
Карточка обновится сама.

---

## 3. Каждую ночь сама

Коробка проверяет себя раз в сутки, около 05:30, без выхода в интернет, и кладёт отчёт туда же, где его видит панель.
Если коробка в это время была выключена, проверка пройдёт после включения.
Делает это таймер systemd `vibedpn-doctor`, его ставит `vibedpn up`.

---

## 4. Командой

На коробке:

```bash
sudo vibedpn doctor
```

С адресами выходов:

```bash
sudo vibedpn doctor --network
```

Для скриптов — `--json`.
`sudo vibedpn doctor --report` делает то же, что ночная проверка: пишет отчёт, который показывает панель.

---

## 5. Если что-то не так

- **Карточка пишет «Проверка не прошла: the host did not check the box»** — хост не выполнил запрос за 5 минут. Смотрите `journalctl -u vibedpn-doctor-request`; если юнитов нет — `sudo vibedpn up` их поставит
- **Отчёта нет вовсе** — ни ночной, ни ручной проверки ещё не было: нажмите «Проверить»
- **Ошибка в отчёте** — подсказка в её строке называет команду, которая чинит; подробнее о симптомах — [troubleshooting.md](../troubleshooting.md)
