# СВОЙ ВЫХОД ПО ФАЙЛУ WIREGUARD

Как дать коробке выход в интернет через чужой сервер, не тратя ни копейки и не заводя кошелёк
Коробке безразлично, чей это сервер: она принимает **готовый файл WireGuard** и поднимает по нему свой шлюз — так же, как туннель к собственной VPS

Зачем это нужно:
Выход через сеть Mysterium требует зарегистрированной identity, а регистрация платная
Сеть берёт около 0.1 MYST плюс газ Polygon, то есть биржу и кошелёк
Файл WireGuard такого не требует

Что понадобится:
- Файл `.conf` от любого поставщика WireGuard
- Панель коробки в браузере; для команд — доступ к коробке по SSH

Ниже — рецепт с бесплатным тарифом Proton, потому что он не стоит денег и разрешает роутер
С любым другим поставщиком шаги те же, меняется только место, где берётся файл

---

## 1. Получить файл

**Шаг 1.** В панели коробки откройте страницу «Выходы»
Блок «Выходы WireGuard» ведёт по шагам и даёт ссылку «Открыть аккаунт Proton VPN»

**Шаг 2.** Заведите бесплатный аккаунт Proton (нужен только адрес почты) и войдите в `account.protonvpn.com`

**Шаг 3.** Откройте **Downloads → WireGuard configuration**

**Шаг 4.** Задайте имя конфигурации и выберите сервер

**Шаг 5.** Скачайте файл `.conf`

Что важно знать про бесплатный тариф:
Роутер разрешён на всех тарифах, включая бесплатный, и считается за одно подключение независимо от числа устройств за ним
Выбор стран на бесплатном тарифе ограничен — какие именно доступны, видно в самом списке серверов

Источники: [файлы WireGuard](https://protonvpn.com/support/wireguard-configurations), [роутер на всех тарифах](https://protonvpn.com/support/installing-protonvpn-on-a-router)

---

## 2. Подключить выход

**Шаг 1.** На странице «Выходы» найдите блок «Добавить выход»
В поле «Файл WireGuard» выберите скачанный файл — или вставьте его текст в поле «или вставьте текст файла»

**Шаг 2.** В поле «Имя выхода» введите имя, например `proton`, и нажмите «Добавить выход»
Коробка сама проверит файл, сохранит его с правами только для root и поднимет выход — ни SSH, ни команд не нужно

**Шаг 3.** Удалите скачанный файл с компьютера: в нём закрытый ключ

Имя выбирается владельцем:
Буквы в нижнем регистре, цифры и `-`, до 24 знаков
Оно становится именем файла, именем контейнера и ключом маршрутизации `wg-proton`

**Проверка:** выход появился в таблице страницы «Выходы», в колонке «Файл» — «на коробке», строка состояния пишет «Применено» со временем

**То же командами.** Положить файл на коробку:

```bash
scp proton.conf dpn@vibedpn.lan:/tmp/proton.conf
```

Подключить и поднять выход:

```bash
sudo vibedpn uplink add proton /tmp/proton.conf
sudo vibedpn up
```

Что делает `uplink add`:
Кладёт файл в `secrets/wg-proton.conf` правами 600 — его читает только root
Добавляет имя в `upstreams.wg` файла `config.yaml`
Больше ничего: трафик пока идёт по-старому, выход поднимает `vibedpn up`

---

## 3. Направить весь трафик через выход

**Шаг 1.** Откройте страницу «Статус», карточку «Маршрутизация»

**Шаг 2.** В строке «Аплинк» нажмите `WG-PROTON`
Строка видна, когда включено больше одного выхода

**Шаг 3.** В строке «Режим» нажмите «Полный — через аплинк» и подтвердите

**Проверка:** на «Статусе» у выхода `WG-PROTON` «Шлюз» — «отвечает»
Настоящую проверку даёт адрес выхода: откройте с устройства LAN любой сайт, показывающий ваш IP
Он должен стать адресом сервера поставщика, а не вашего провайдера

**То же командами.**

```bash
sudo vibedpn upstream wg-proton
sudo vibedpn mode full
sudo vibedpn status
```

В строке аплинков появится `wg-proton`, а у него — живой шлюз

---

## 4. Несколько выходов сразу

Имён может быть до восьми, и они живут одновременно

**Шаг 1.** На странице «Выходы» добавьте следующий файл через «Добавить выход» под своим именем, например `mullvad`

**Шаг 2.** Переключайтесь между выходами на «Статусе», карточка «Маршрутизация», строка «Аплинк»
Перезапуска коробки не требуется

Каждый получает свой контейнер-шлюз, свою таблицу маршрутизации и свой kill-switch

**Проверка:** все выходы видны в таблице страницы «Выходы»

**То же командами.**

```bash
sudo vibedpn uplink add mullvad /tmp/mullvad.conf
sudo vibedpn uplink show
sudo vibedpn upstream wg-mullvad
```

## 5. Только отдельные сайты через выход

Весь трафик через выход не нужен — можно отправить туда только некоторые сайты, остальное пойдёт напрямую
Это умный режим

**Шаг 1.** Откройте страницу «Правила»
В поле «Сайт» введите, например, `youtube.com`, канал — «Через свой выход WireGuard», рядом выберите выход `wg-proton`, нажмите «Добавить правило»

**Шаг 2.** Готовый список сайтов по URL — на той же странице, блок «Списки доменов»
Поле «URL списка», тот же канал и выход, кнопка «Добавить список»

**Шаг 3.** Включите умный режим
В панели переключателя умного режима нет: в карточке «Маршрутизация» только «Выключен — LAN напрямую» и «Полный — через аплинк» — умный режим включается командой `sudo vibedpn mode smart`

**Проверка:** на «Статусе» заголовок «Сайты по правилам — через wg-proton, остальное напрямую»

**То же командами.**

```bash
sudo vibedpn rule add youtube.com wg --uplink proton
sudo vibedpn lists add <url> wg --uplink proton
sudo vibedpn mode smart
```

Разные сайты могут идти через разные выходы одновременно: у каждого выхода свой набор адресов, своя метка и свой kill-switch
Правило требует, чтобы выход был описан в `upstreams.wg` и включён
Иначе конфиг не примет его, как не примет правило через выключенный VPS

---

## 6. Убрать выход

**Шаг 1.** На странице «Выходы» в строке выхода нажмите «Удалить» и подтвердите
Коробка снимет выход вместе с файлом и сама применит изменение

**Проверка:** выхода нет в таблице страницы «Выходы»

**То же командами.**

```bash
sudo vibedpn uplink rm proton
sudo vibedpn up
```

Выход снимается вместе с файлом `secrets/wg-proton.conf`: закрытому ключу выхода, которого на коробке больше нет, незачем на ней оставаться

## 7. Если что-то не так

Сначала — панель:
- На странице «Выходы» карточка «Журналы»: выберите службу `wg-<имя>` и нажмите «Показать»
- На «Статусе» та же карточка «Журналы» есть для всех служб
- На «Статусе» карточка «Проверка коробки», кнопка «Проверить» — пройдёт по коробке и назовёт, что сломано

**Контейнер выхода не поднялся.** Значит нет файла `secrets/wg-<имя>.conf` либо он не читается
Коробка этот файл не создаёт и не выпрашивает — без него выхода нет
В панели: в таблице страницы «Выходы» в колонке «Файл» стоит «нет файла»
Командой:

```bash
sudo ls -l /opt/vibedpn/secrets/
```

**Шлюз не отвечает.** Смотрите журнал службы `wg-<имя>` в карточке «Журналы»
Чаще всего это устаревший файл (поставщик отозвал ключ) или закрытый исходящий UDP у вашего провайдера
Командой:

```bash
sudo vibedpn logs wg-<имя>
```

**Трафик стоит.** Так и задумано при `routing.failopen: false`: упал аплинк — трафик не идёт мимо туннеля
Чтобы в этом случае выходить напрямую, откройте «Статус» → «Маршрутизация» и нажмите «Пускать напрямую» в строке «Не отвечает ни один выход» — это осознанный выбор
Командой:

```bash
sudo vibedpn failopen on
```
