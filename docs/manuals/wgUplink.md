# Свой выход по файлу WireGuard

Как дать коробке выход в интернет через чужой сервер, не тратя ни копейки и не заводя кошелёк.
Коробке безразлично, чей это сервер: она принимает **готовый файл WireGuard** и поднимает по нему
свой шлюз — так же, как туннель к собственной VPS.

Зачем это нужно: выход через сеть Mysterium требует зарегистрированной identity, а регистрация
платная — сеть берёт около 0.1 MYST плюс газ Polygon, то есть биржу и кошелёк. Файл WireGuard
такого не требует.

## Проще всего — через панель

Откройте в панели коробки страницу **«Выходы»**. Там по шагам: ссылка на аккаунт Proton VPN,
где нажать, выбор скачанного файла или вставка его текста и имя выхода. Коробка сама проверит файл,
сохранит его с правами только для root и поднимет выход — ни SSH, ни команд не нужно. Строка
состояния на той же странице скажет, когда выход применён или что пошло не так.

Ниже — то же самое из терминала.

## Что понадобится

- Файл `.conf` от любого поставщика WireGuard
- Доступ к коробке по SSH

Ниже — рецепт с бесплатным тарифом Proton, потому что он не стоит денег и разрешает роутер.
С любым другим поставщиком шаги те же, меняется только место, где берётся файл.

## 1. Получить файл

1. Завести бесплатный аккаунт Proton (нужен только адрес почты) и войти в `account.protonvpn.com`
2. Открыть **Downloads → WireGuard configuration**
3. Задать имя конфигурации и выбрать сервер
4. Скачать файл `.conf`

Что важно знать про бесплатный тариф:
Роутер разрешён на всех тарифах, включая бесплатный, и считается за одно подключение независимо
от числа устройств за ним.
Выбор стран на бесплатном тарифе ограничен — какие именно доступны, видно в самом списке серверов.

Источники: [файлы WireGuard](https://protonvpn.com/support/wireguard-configurations),
[роутер на всех тарифах](https://protonvpn.com/support/installing-protonvpn-on-a-router).

## 2. Положить файл на коробку

```bash
scp proton.conf dpn@vibedpn.lan:/tmp/proton.conf
```

## 3. Подключить выход

```bash
sudo vibedpn uplink add proton /tmp/proton.conf
```

Что делает команда:
Кладёт файл в `secrets/wg-proton.conf` правами 600 — его читает только root.
Добавляет имя в `upstreams.wg` файла `config.yaml`.
Больше ничего: трафик пока идёт по-старому.

Имя выбирается владельцем: буквы в нижнем регистре, цифры и `-`, до 24 знаков.
Оно становится именем файла, именем контейнера и ключом маршрутизации `wg-proton`.

## 4. Поднять и направить трафик

```bash
sudo vibedpn up
sudo vibedpn upstream wg-proton
sudo vibedpn mode full
```

Проверить:

```bash
sudo vibedpn status
```

В строке аплинков появится `wg-proton`, а у него — живой шлюз.
Настоящую проверку даёт адрес выхода: откройте с устройства LAN любой сайт, показывающий ваш IP —
он должен стать адресом сервера поставщика, а не вашего провайдера.

## Несколько выходов сразу

Имён может быть до восьми, и они живут одновременно:

```bash
sudo vibedpn uplink add mullvad /tmp/mullvad.conf
sudo vibedpn uplink show
```

Каждый получает свой контейнер-шлюз, свою таблицу маршрутизации и свой kill-switch.
Переключение между ними — `vibedpn upstream wg-<имя>`, перезапуска коробки не требуется.

## Убрать выход

```bash
sudo vibedpn uplink rm proton
sudo vibedpn up
```

Команда снимает выход вместе с файлом `secrets/wg-proton.conf`: закрытому ключу выхода, которого на
коробке больше нет, незачем на ней оставаться. В панели кнопка «Удалить» делает то же и сама применяет изменение.

## Если что-то не так

**Контейнер выхода не поднялся.** Значит нет файла `secrets/wg-<имя>.conf` либо он не читается.
Коробка этот файл не создаёт и не выпрашивает — без него выхода нет. Проверить:
`sudo ls -l /opt/vibedpn/secrets/`.

**Шлюз не отвечает.** Смотрите журнал: `sudo vibedpn logs wg-<имя>`. Чаще всего это устаревший
файл (поставщик отозвал ключ) или закрытый исходящий UDP у вашего провайдера.

**Трафик стоит.** Так и задумано при `routing.failopen: false`: упал аплинк — трафик не идёт мимо
туннеля. Чтобы в этом случае выходить напрямую, поставьте `failopen: true` — это осознанный выбор.

## Только отдельные сайты через выход

Весь трафик через выход не нужен — можно отправить туда только некоторые сайты, остальное пойдёт
напрямую. Это умный режим:

```bash
sudo vibedpn rule add youtube.com wg --uplink proton
sudo vibedpn mode smart
```

То же в панели: страница «Правила», канал «Через свой выход WireGuard», рядом выбор выхода.
Готовый список сайтов по URL отправляется так же: `vibedpn lists add <url> wg --uplink proton`.

Разные сайты могут идти через разные выходы одновременно: у каждого выхода свой набор адресов,
своя метка и свой kill-switch. Правило требует, чтобы выход был описан в `upstreams.wg` и включён —
иначе конфиг не примет его, как не примет правило через выключенный VPS.
