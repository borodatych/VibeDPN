# ЯЗЫКОВОЙ ФАЙЛ ПАНЕЛИ VIBEDPN

**Скопируйте этот файл целиком своей LLM и попросите собрать `<код>.json` — перевод панели VibeDPN на нужный язык.**
Модели не нужны ни интернет, ни исходники: всё, что требуется, описано ниже.

---

## 1. Что это за файл

Панель коробки говорит на английском: он встроен в неё и служит базой.
Любой другой язык — один JSON-файл в папке `data/ui/locales/` коробки (обычно `/opt/vibedpn/data/ui/locales/`).
Имя файла — двухбуквенный код языка ISO 639-1 в нижнем регистре: `ru.json`, `de.json`, `uk.json`.
Файл появился — язык есть в переключателе в шапке панели; удалили — язык исчез, панель заговорит на языке по умолчанию или по-английски.
Язык по умолчанию задаёт `ui.language` в `config.yaml`; браузер может выбрать другой переключателем.
Папка читается при старте панели: после правки файла — `sudo docker restart vibedpn-ui-1` (или `sudo vibedpn restart`).

Тот же файл говорит и за Telegram-бота коробки: его сообщения — ключи с префиксом `bot.` (`bot.uplink.down`, `bot.report.title`).
Их читает ядро на языке `ui.language`, тоже один раз, при старте: после правки таких строк — `sudo vibedpn restart`.
Ключа `bot.*` нет — бот пишет эту фразу по-английски.

---

## 2. Формат

Один JSON-объект: ключ — строка панели, значение — её перевод.
Ключи плоские, с точками: `"nav.status"`, `"rules.column.site"`.

```json
{
  "language.name": "Deutsch",
  "nav.status": "Status",
  "status.headline.through": "Das LAN geht über {uplink} hinaus",
  "devices.nameOf": "Name von {device}"
}
```

Правила:
- `language.name` — название языка на самом языке; его показывает переключатель.
- Подстановки в фигурных скобках (`{uplink}`, `{count}`, `{domain}`) переносятся без изменений: имя внутри скобок не переводится, скобку можно передвинуть в любое место фразы.
- Неизвестные ключи и значения не-строки игнорируются.
- Ключа нет — панель покажет английскую строку: половина перевода уже полезна.
- Не переводятся: `VibeDPN`, `MYST`, `AdGuard`, `Mysterium`, `VPS`, `LAN`, `WAN`, `DNS`, `CDN`, `MAC`, `URL`, `failopen`, `kill-switch`, имена команд (`vibedpn restart`, `vibedpn doctor`, `vibedpn init`) и `config.yaml`.
- Файл английского (`en.json`) класть не нужно: он перекроет встроенные строки и заморозит их — исправления английского в новых версиях до вас не дойдут.
- Языки, которые приходят с панелью (сейчас `ru.json`), обновляются вместе с ней, пока вы их не правили: панель помнит, какой файл положила сама (`data/ui/locales/.seeded/`). Поправили файл — он ваш, и новые версии его больше не заменяют; новые строки в нём тогда будут по-английски, пока вы их не добавите.

## 3. Полный список ключей

Источник ключей и английских строк панели — `ui/src/modules/i18n/base.ts` репозитория, ключей бота `bot.*` — `core/vibedpn/engine/i18n.py`; готовый пример перевода обоих — `ui/locales/ru.json`.
Отдайте модели эти файлы вместе с этой спекой: перевод собирается из `ru.json` заменой значений, набор ключей при этом не меняется.
Проверка панели в репозитории падает, если в поставляемом переводе не хватает ключа панели, есть лишний или у строки другой набор подстановок; то же для ключей `bot.*` проверяет тест ядра.

Особые ключи бота — формы чисел и дат, их тоже можно переставлять:
- `bot.format.decimal` — дробное число: `{whole}.{fraction}` по-английски, `{whole},{fraction}` по-русски;
- `bot.format.date` и `bot.format.time` — дата и время: `{year}-{month}-{day}` и `{day}.{month}.{year}`, `{hour}:{minute}`;
- `bot.unit.*` — единицы: `{count} min`, `{count} МБ`; в отчёте их склеивает сам бот, склонений нет — нужны сокращения.

---

## 4. Как проверить свой файл

1. JSON валиден: `python3 -m json.tool de.json > /dev/null`.
2. В каждой строке те же `{…}`, что в английской.
3. Положите файл в `data/ui/locales/`, перезапустите панель, выберите язык в шапке.
