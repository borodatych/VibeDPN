# ГОЛЫЙ VPS ДЛЯ ЧЕЛОВЕКА В РОССИИ

Как поднять свою VPS без ноды Mysterium: туннель для телефонов, ноутбуков и домашних коробок и доступ по ссылке VLESS/REALITY.
Туннель — AmneziaWG 3.1: обычный WireGuard ТСПУ узнаёт по сигнатуре, AmneziaWG прячет её.
Подробности протокола и границы параметров — [knowledge/wireguard/amnezia.md](../knowledge/wireguard/amnezia.md).

---

## 1. Что получится

На VPS работают два сервера и больше ничего:
- туннель AmneziaWG: по файлу или QR-коду на каждое устройство;
- сервер доступа VLESS/REALITY: по ссылке на каждого человека

Нет ноды, панели, AdGuard и пароля: проверять пароль нечему, его не спрашивают

---

## 2. Что нужно

- VPS вне России с публичным IPv4, Debian или Ubuntu, 1 ГиБ памяти хватает
- Устройство `/dev/net/tun` (на большинстве VPS есть; на OpenVZ спросите у хостера)
- Доступ по ssh с правами root

---

## 3. Установить

На VPS:

```bash
curl -fsSL https://raw.githubusercontent.com/borodatych/VibeDPN/main/install.sh | sudo sh
sudo vibedpn init --role vps --no-provider --access
sudo vibedpn up
```

Что делают флаги `init`:
- `--no-provider` — без ноды (это умолчание для `vps`; `--provider` вернёт ноду и пароль панели);
- `--access` — сразу включить сервер доступа; его ссылки называют публичный адрес VPS;
- `--endpoint <адрес>` — если мастер не смог определить публичный адрес (VPS за NAT)

`init` сам придумывает случайные параметры маскировки и пишет их в `config.yaml`, блок `wg_server.awg`.
Ключ защиты заголовков — секрет: он в `secrets/wg-server/header-protection.key`, в конфиг не попадает и в журналах заменяется на `***`

Проверка: `sudo vibedpn doctor` — строки `[FAIL]` быть не должно

---

## 4. Устройство: телефон или ноутбук

На VPS:

```bash
sudo vibedpn peer add phone
```

Команда печатает файл и QR-код. Файл можно записать: `sudo vibedpn peer add phone --out phone.conf`.
Повторно: `sudo vibedpn peer export phone`

В файле весь трафик идёт через VPS (`AllowedIPs = 0.0.0.0/0`).
QR-код держит файл целиком: комментарии в него не входят, ширина около 70 столбцов терминала.
Узкий терминал рвёт картинку — тогда берите файл через `--out`

Приложения, которые понимают AmneziaWG 3.1 (проверка по датам выпусков, на живом устройстве не проверялась):
- AmneziaWG для Android;
- AmneziaVPN для рабочего стола и Android, версия 5.0.1.5 и новее;
- AmneziaWG для Windows 3.1.0 и новее;
- iOS и macOS: в исходниках есть тег 3.1, выпуск в App Store не проверен

Обычный клиент WireGuard такой файл не примет: ключи маскировки ему незнакомы.
Импорт: в приложении «добавить туннель» — из файла или со сканированием QR-кода

---

## 5. Российские сайты напрямую

Файл гонит через VPS всё. Российские сайты при этом видят адрес VPS за границей и могут не работать.
Исключения задаёт приложение, а не VPS: у AmneziaWG и AmneziaVPN есть раздельное туннелирование по приложениям и по адресам.
Выберите приложения или сайты, которые должны идти напрямую, и оставьте через туннель остальное

---

## 6. Домашняя коробка

Домашней коробке тот же файл выдаёт `vibedpn peer add home`, а на коробке — `sudo vibedpn init --role client --peer-config home.conf`.
Это та же связка, что и с нодой: [multiVps.md](multiVps.md), [wgUplink.md](wgUplink.md)

---

## 7. Люди по ссылке

Для тех, кому ставить приложение туннеля сложно: ссылка VLESS/REALITY.

```bash
sudo vibedpn access add anna
```

Команда печатает ссылку и QR-код. Приложения, их настройка и сайт-прикрытие — в [accessServer.md](accessServer.md).
Включить сервер потом можно и без `--access` при `init`: `sudo vibedpn access enable`, затем `sudo vibedpn up`

---

## 8. Включить или выключить маскировку позже

```bash
sudo vibedpn awg enable    # новые случайные параметры в config.yaml
sudo vibedpn awg disable   # обычный WireGuard
sudo vibedpn up
```

После любого из них файлы пиров меняются: выдайте каждому заново (`vibedpn peer export <имя>`), старые перестанут работать.
Выключили и включили снова — ключ защиты заголовков тоже новый

---

## 9. Если рукопожатие пропало

1. `sudo vibedpn peer list` — у пира «handshake never» или давно: до сервера пакеты не доходят
2. `sudo vibedpn doctor` — порт туннеля (`51820/udp` по умолчанию) должен быть открыт, `wg-server` — здоров
3. Файл устройства старый: после `awg enable/disable`, смены порта или подсети нужен свежий `peer export`
4. Хостер или провайдер режет порт: смените `wg_server.listen_port` в `config.yaml`, `vibedpn up`, выдайте файлы заново
5. Блокировка поймала и маскировку: параметры можно обновить `awg disable`, `awg enable`, `up` и новыми файлами; сработает ли — зависит от блокировки, **против живого ТСПУ не проверено**
6. Запасной путь — ссылка VLESS/REALITY (раздел 7): другой протокол и порт 443

---

## 10. Что не проверено

- голый VPS на настоящей машине: стенд `tests/e2e/vps.sh` гоняет его на одном хосте с Docker;
- AmneziaWG против живого ТСПУ;
- приложения на настоящих телефонах с файлом 3.1
