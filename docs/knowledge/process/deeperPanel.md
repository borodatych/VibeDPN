# Панель Deeper Connect: что видно снаружи и изнутри

Снято 2026-09-17 с устройства владельца (серийный `Deeper-Wire-HW-…`, прошивка 2.0.6.h3,
4 ядра, 1 ГБ) только чтением: веб-интерфейс скачан без входа, API — GET-запросами из
залогиненной вкладки. Код Deeper в проект не переносится — лицензия закрытая
(knowledge `process/licensing.md`); здесь только устройство продукта.
Копия интерфейса — `/Volumes/Storage/Caches/deeper/web` (175 JS-файлов, 7 МБ).

## Как устроено

- Панель: `http://11.22.33.44` (без TLS) и `https://34.34.34.34` (самоподписанный сертификат
  `CN=local.deeper.network`, выдан Deeper Network Inc.). Сервер — Express, клиент — React SPA
  на Vite, вход `POST /api/admin/login` с паролем, который клиент хеширует перед отправкой.
- 144 пути API в бандле. Группы: `smartRoute` (режим DPN, туннели, списки доменов и адресов),
  `appRelocator` (126 готовых сервисов со страной по умолчанию), `sharing` (раздача канала),
  `betanet` и `wallet` (кошелёк, кредит, стейкинг), `microPayment`, `tproxy` (HTTPS-фильтр
  рекламы со своим корневым сертификатом), `security`, `accessControl`, `rustdesk`, `wifi`.
- Протокола DPN в веб-интерфейсе нет: туннели строит прошивка (AtomOS), панель только
  выбирает страну. Подключиться к их сети без их устройства по материалам панели нельзя.

## Маршрутизация

- Режимы: `smart` («Smart Routing»), `full`, `disabled` («Direct Routing»); у устройства LAN
  ещё `blackHole`. На устройстве владельца — `smart`, туннель по умолчанию `NL`,
  балансировка узлов `nodeLbMode: domain`.
- Туннель = страна: 15 туннелей, у каждого `activeNum` — число живых узлов (1–6), половина
  добавлена владельцем. Резервный туннель подхватывает, если основной упал.
- Белый список доменов с кодом туннеля (65 записей: трекеры, Telegram, сервисы ИИ, 4pda
  и т. п.) и чёрный — «всегда напрямую» (32 российских сервиса: банки, маркетплейсы, VK,
  Яндекс, госуслуги — они ломаются с зарубежного адреса). Список адресов пуст.
  Это та же модель, что `routing.domains` + `direct` у нас.

## Экономика

- `GET /api/microPayment/getDailyTraffic` за сутки: потреблено 27.3 ГБ, роздано 45 МБ,
  раздача включена, лимита трафика нет. Пользование не привязано к раздаче день в день —
  доступ оплачивается устройством и кредитом, а не текущим заработком.
- Кредит и баланс закрыты за разблокировкой кошелька (`403 walletLocked`) — не читались.

## Что это значит для VibeDPN

- «Как Deeper» для пользователя — это умный режим со списками «через выход» и «всегда
  напрямую» плюс готовые наборы сервисов со страной. Это у нас уже есть или ложится на
  `routing.domains` и `routing.lists`.
- Их бесплатность для пользователя держится на покупке железа, а не на балансе
  «раздал = потребил». Замкнуть круг на заработке ноды так, как у них, не получится.
