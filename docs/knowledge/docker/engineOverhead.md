# Сколько памяти стоит Docker на коробке

## [платформа] Накладные расходы Docker и почему Colima их не уменьшит

**Контекст:** бюджет коробки — 4 ГБ (решение владельца 2026-09-13), вопрос «не прожорлив ли Docker».
**Замер (2026-09-13, Docker в VM colima aarch64, Docker Engine перезапущен перед замером):**
- `dockerd` — 87 МиБ, `containerd` — 48 МиБ без контейнеров;
- каждый контейнер добавляет `containerd-shim` ~10 МиБ (два `sleep`-контейнера — 20.5 МиБ на два), сам процесс внутри — столько же, сколько без Docker;
- после десятка сборок образов `dockerd` вырос до 143 МиБ: кэш сборки живёт в демоне, на коробке образы не собираются.
**Итог для коробки:** при ~9 сервисах Docker стоит около 225 МиБ сверх самих процессов — меньше 6 % от 4 ГБ.
Контейнер — это пространства имён ядра, а не виртуальная машина: приложение внутри занимает ту же память, что и на хосте.
**Colima** — это Docker (или containerd) внутри виртуальной машины Lima: «Containers on Lima», по умолчанию VM на 2 CPU и 2 GiB.
На macOS она нужна, потому что там нет ядра Linux; на Linux-коробке она добавила бы целую ОС гостя поверх того же Docker, то есть памяти стало бы больше, а не меньше.
Colima в проекте — только среда разработки на Mac (`docs/manuals/devSetup.md`).
**Источники:** https://github.com/abiosoft/colima .
