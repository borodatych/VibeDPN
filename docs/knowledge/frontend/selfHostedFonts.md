# Шрифты панели — с самой коробки

**Контекст:** панель `ui/` на Point0 0.3.10 и Bun 1.3.14 (в образе 1.4.2); найдено и сделано 2026-10-01.

## [решение] Почему не Google Fonts

Пак start0 подключал шрифты ссылкой на `fonts.googleapis.com`, файлы шли с `fonts.gstatic.com`.
Каждый заход в панель сообщал Google о коробке, а медленная линия до него держала `load` страницы.
Замер на собранной панели, `/sign-in`, три захода: до — 7,2–7,3 с, после — 85–183 мс.
Тесты e2e на тайм-ауте 20 с падали на сети, а не на панели.

## [грабли] Импорт CSS Fontsource в стиль панели не годится

`@import '@fontsource-variable/inter/wght.css'` в `styles/index.css` упирается в две вещи.

Первая — плагин ресурсов Point0 (`@point0/compiler`, `assets.js`).
Он перехватывает `.woff` и `.woff2` и делает из файла JS-модуль со ссылкой.
JS-импорту это подходит, а `url()` в CSS ломает сборку: «Cannot import a ".js" file into a CSS file».
Шрифты убираются из плагина настройкой `assets.extensions`.

Вторая — сам Bun.
Файл из `url()` в CSS меньше 128 КБ он всегда встраивает как `data:`: порог `COPY_THRESHOLD` зашит.
Загрузчик `file`, `naming.asset` и `publicPath` на `url()` в CSS не действуют.
Источник — ответ команды Bun в https://github.com/oven-sh/bun/issues/37975, запрос на настройку — https://github.com/oven-sh/bun/issues/24599.
Проверено голым `Bun.build` на одном `latin-700.css`: `data:font` в выводе и с загрузчиком `file`, и без него.
Для трёх шрифтов это 416 КБ файлов, то есть около 555 КБ base64 в блокирующем CSS, и браузер получает все подмножества сразу.

## [решение] `fonts.css` из CSS пакетов, файлы — через `publicdir`

`ui/src/lib/fonts.build.ts` (`panelFonts`) читает CSS пакетов Fontsource и переписывает `url(./files/…)` на `/fonts/<пакет>/…`.
`engine.ts` отдаёт результат через `publicdir` клиента: строка `fonts.css` функцией и каталоги `files` пакетов.
`App` подключает `/fonts.css` через `<Head>`, как значки.
Своей копии `@font-face` нет: правила и `unicode-range` берутся из пакета, обновление пакета их не разведёт.
`unicode-range` сохраняется, поэтому браузер качает только нужные подмножества.
На странице входа это пять файлов: латиница всех трёх шрифтов и кириллица Fira Code и IBM Plex Serif.

`publicdir` Point0 копирует только каталоги.
Отдельный файл маршрутом не отдать, а функция возвращает только строку, бинарный файл ей не передать.
Поэтому каталоги `files` уходят в сборку целиком: 3,9 МБ вместо нужных 416 КБ.

Пакеты лежат в `dependencies`: `engine.ts` читает их и при старте собранного сервера, а рантайм-образ ставит только production-зависимости.

## [гейт]

`ui/src/lib/fonts.build.unit.test.ts`: каждый `url()` в `fonts.css` указывает на существующий файл под маршрутом панели.
Подмена адреса роняет тест.
`panelContext` в `ui/src/test/lib/e2e.ts` обрывает любой запрос не к `localhost` и записывает его в `thirdPartyRequests`.
Smoke-тест «the panel loads nothing from outside the box» падает, если запись есть.
Возврат ссылки на Google в `<Head>` его роняет.
