# `point0 dev --hot`: контекст React в двух экземплярах

**Контекст:** панель `ui/` на Point0 0.3.10, `bun run dev` — это `point0 dev --hot`; найдено 2026-10-01.

## [грабли] Под `--hot` сервер рендерит страницы базовым языком, клиент — выбранным

Симптом: на каждой странице «Hydration failed…», React перестраивает дерево на клиенте.
Расхождение — подписи: сервер пишет «Sign in to VibeDPN» и «Loading...», клиент — «Вход в VibeDPN» и «Загрузка…».
Под `point0 dev` без `--hot` и в собранной панели сервер отдаёт русский, и расхождения нет.

Причина — экспериментальный режим `--hot`.
Point0 копирует модули точек в своё хранилище `node_modules/.cache/server-hot/<scope>-<port>/` и переписывает их импорты на копии.
`app.client.tsx` в хранилище не попадает: он остаётся холодным и импортирует исходные модули.
Модуль, нужный обоим, существует дважды, и `createContext` в нём вызывается дважды.
`LanguageProvider` в `App` наполняет контекст исходного `use-t.tsx`.
Страницы и шапка читают контекст копии и получают значение по умолчанию — базовый английский.

Отладка, которая это показала: строка в `LanguageProvider` писала `languageQuery` при серверном рендере.
Провайдер видел `success` и `ru` в обоих режимах, а HTML под `--hot` оставался английским — значит, читатели смотрели в другой контекст.
`console.log` из серверного рендера под `--hot` в вывод `bun run dev` не попадал — писать в файл.

**Решение:** модуль с контекстом импортирует метку `@point0/core/cold` первой строкой.
Холодный модуль и всё, что он импортирует, Point0 в хранилище не копирует, поэтому `App` и страницы берут один экземпляр.
Цена: правка такого файла под `--hot` перезапускает сервер вместо подмены модуля.
Помечены `modules/i18n/use-t.tsx`, `components/ui/section.tsx`, `modules/form/core/context.tsx`.
Ломал рендер только первый: его провайдер стоит в `App`.
Два других помечены, чтобы правило было простым: первый же их провайдер в `App` сломался бы так же.

**Гейт:** `ui/src/app.client.unit.test.ts` обходит граф импортов `App` и падает на модуле с `createContext`, который не холодный.
Холодными считаются файлы с импортом метки и всё, что они импортируют.
Обход импортов у этого гейта и у гейта `root` общий — `ui/src/test/lib/imports.ts`.
Вызов ищется регуляркой `createContext\s*[<(]`: поиск по `createContext(` пропускал типизированный `createContext<State>(`, и гейт проходил на сломанном коде.

**Проверено:** гейт падает до правки на трёх модулях и проходит после.
Под `bun run dev`: серверный HTML `/sign-in` — «Вход в VibeDPN», в консоли браузера ноль ошибок на шести страницах в светлой и тёмной схемах.
