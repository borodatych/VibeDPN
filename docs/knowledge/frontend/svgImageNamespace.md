# SVG картинкой: без xmlns не рисуется

**Контекст:** QR-коды ссылок в панели (страницы «Доступ» и «Уведомления»), 2026-09-23.

## [грабли] segno.svg_inline отдаёт SVG для вставки в HTML, не для картинки

Панель показывает QR, который рисует ядро, через `<img src="data:image/svg+xml,...">`: картинка не выполняет ничего, что мог бы нести SVG.
Ядро строило его `segno.make(...).svg_inline(...)`, а этот метод сохраняет SVG с `svgns=False` — без пространства имён, для вставки прямо в HTML.
SVG-документ без `xmlns` картинкой не рисуется: на стенде 23.09.2026 у такого `<img>` было `naturalWidth` 0, и вместо кода виден пустой прямоугольник с подписью.
MDN: `xmlns` обязателен у внешнего `svg` SVG-документа и не нужен только внутри HTML с HTML-сериализацией.
**Как применять:** QR для картинки — `save(buffer, kind="svg", xmldecl=False, svgns=True, ...)`, целый документ; тесты API сервера доступа и бота проверяют `xmlns="http://www.w3.org/2000/svg"` в ответе.

**Источники:** https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/svg (когда нужен `xmlns`); исходник segno 1.6.6, `QRCode.svg_inline` (`svgns=False`).
