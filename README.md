# VibeDPN

Open-source «DPN-коробка» для своих: одна кодовая база, из которой одной командой собирается либо
домашний all-in-one роутер, либо связка «нода на VPS + клиент дома». Аналог Deeper Connect, но на
своём железе (Raspberry Pi 4/5, мини-ПК на N100, любой Debian-хост) и с открытым dVPN-бэкендом
(Mysterium) вместо закрытого AtomOS.

> **Статус: v0.1.0, первый выпуск.** Роль `home` живёт на домашнем железе (мини-ПК N100, Debian 13)
> и работает каждый день: роутер во всех трёх режимах, политики устройств, kill-switch, AdGuard,
> точка доступа Wi-Fi с телефонами семьи, панель и выход через Tor.
> Роль `client` с туннелем к своей VPS и выход по готовому файлу WireGuard проверены сквозными
> стендами в CI: адресом выхода, а не показаниями счётчиков.
>
> Что **не проверено на живом железе** и названо честно: роль `vps` на настоящей VPS (только стенды
> и CI), сессия в сети Mysterium с реальной регистрацией identity (она стоит денег — коробка её сама
> не начинает), готовые образы ОС — UEFI-образ загружается и настраивается в QEMU, образ Raspberry Pi
> разобран и запускает свой CLI в chroot, но ни один ещё не загружался на настоящей плате.
> Что закрыто и что впереди — [docs/roadmap.md](docs/roadmap.md), каталог возможностей —
> [docs/functional.md](docs/functional.md), если что-то не работает —
> [docs/troubleshooting.md](docs/troubleshooting.md).

## Что делает коробка

- **Раздаёт канал** в Mysterium Network как exit-нода и получает MYST (роль provider).
- **Гонит трафик** домашних устройств через туннель: либо через собственную VPS (бесплатно и
  быстро), либо через любую ноду Mysterium с выбором страны (роль consumer), либо через Tor по
  мостам Snowflake — бесплатно, без аккаунтов и криптовалюты, включается одной кнопкой.
- **Роутер:** режимы Off / Full / Smart, политика на каждое устройство, kill-switch, адблок через
  AdGuard Home. В Smart у каждого сайта свой канал — VPS, Mysterium или напрямую, CDN сайта идёт
  за ним сам, а снифер `vibedpn dns watch` показывает, куда ушёл каждый запрос устройства.
- **Пускает своих из любой сети:** каждому человеку ссылка или QR-код на свой маскирующий
  сервер, и телефон снаружи получает домашние правила — заблокированное через Tor, реклама режется.
- **Пишет в Telegram:** тревоги «выход молчит», «коробка снова в сети», «адрес сменился» и недельный
  отчёт о заработке ноды и простоях — от вашего бота, через ваши же выходы и правила.
- **Ставится одной строкой** и настраивается мастером `vibedpn init` — целевой пользователь не
  сетевик.

Что это **не**: не форк Deeper, не свой блокчейн. Протокольный слой — чужой и открытый, VibeDPN
делает удобную обвязку и роутер.

## Три сценария

**Одна коробка дома (`home`).** Raspberry Pi или мини-ПК стоит в вашей LAN рядом с обычным
роутером. Устройства указывают её шлюзом и DNS (руками или DHCP-опцией на роутере) — и получают
адблок, kill-switch и выход в интернет через ноду Mysterium в выбранной стране. Та же коробка
одновременно работает нодой и зарабатывает MYST. Помните: exit-нода — это чужой трафик с вашего
домашнего IP, абузы придут вам; безопаснее держать ноду на VPS.

**Нода на VPS (`vps`).** На арендованном сервере крутится myst-нода, которая приносит MYST, и
приватный WireGuard-сервер для ваших домашних коробок. Панель ноды и API коробки наружу не
торчат — только через туннель. Один VPS обслуживает несколько домов: `vibedpn peer add <имя>`
выдаёт конфиг и QR.

**Клиент дома, в паре с VPS (`client`).** Домашняя коробка поднимает WireGuard-туннель к вашей
VPS и гонит через него трафик LAN — бесплатно и быстро, без чужих нод. Дополнительно можно
включить выход через сеть Mysterium с выбором страны. Роутер, политики устройств и AdGuard —
те же, что в `home`; ноды дома нет.

Подробно о ролях — [docs/roles.md](docs/roles.md); концепт и архитектура —
[docs/idea.md](docs/idea.md).

## Одна коробка: всё сразу

Роль `home` поднимает на одной машине ноду Mysterium, выход через сеть Mysterium, роутер LAN,
AdGuard и панель.

1. Установите VibeDPN (раздел «Установка» ниже) и настройте коробку:

   ```bash
   sudo vibedpn init --role home
   ```

   Мастер найдёт интерфейс и адрес коробки в LAN и спросит пароль — он открывает панель, API и панель
   ноды. Вариант панели (`full` или `lite`) выбирается по памяти, `--ui-variant` задаёт его явно.
2. Запустите:

   ```bash
   sudo vibedpn up
   ```

3. Направьте устройства на коробку — раздел «Как направить устройства через коробку». Панель
   откроется на `http://vibedpn.lan` у устройств, которые спрашивают DNS у коробки.
4. **Нода за роутером (NAT).** Пробросьте на роутере UDP-диапазон ноды на адрес коробки — по
   умолчанию `56000-56100` (`provider.udp_ports`). Без проброса нода пробует обойти NAT сама
   (`provider.traversal`: `manual`, `upnp`, `holepunching`), но потребителей до неё доходит меньше.
   Что думает о своём NAT сама нода, покажет:

   ```bash
   sudo vibedpn doctor --network
   ```

   Строка `nat`: `fullcone` или `none` — нода достижима напрямую, `rcone` или `prcone` — через hole
   punching, `symmetric` — пробросьте диапазон. Это оценка ноды: открыт ли диапазон из интернета,
   видно только снаружи.

Трафик самой ноды идёт в интернет напрямую, мимо туннелей и режима `full`: роутер коробки
направляет в аплинки только трафик устройств LAN.

## Как пополнить выход через Mysterium

Аплинк `dpn` ходит в интернет через ноды сети Mysterium и платит им в токенах MYST. Коробка сама создаёт
для этого consumer-identity (ключ — в `data/myst-consumer`, парольная фраза — в
`secrets/myst-consumer-passphrase`), но ни регистрировать её, ни платить молча не станет.

1. **Узнайте адрес пополнения.** Это `channel_address` identity — строка «Top up» в карточке
   «Mysterium exit (dpn)» на экране статуса панели или поле `channel_address` блока `dpn` в статусе ядра:

   ```bash
   curl -s http://127.0.0.1:4480/status
   ```

2. **Переведите на него MYST в сети Polygon** — не Ethereum. Контракт MYST на Polygon —
   `0x1379e8886a944d2d9d440b3d88df536aea08d9f3`, 18 знаков. Купить MYST на Polygon можно, например, на MEXC
   (с выводом в Polygon), в пуле Uniswap V3 или на Quickswap. Пока identity не зарегистрирована, её баланс —
   это MYST на адресе канала.
3. **Регистрация.** Бесплатна, только если нода разрешает это для identity; иначе при регистрации
   списывается комиссия транзактора из баланса.

**Сколько стоит.** Цену назначает сама сеть — за час соединения и за гигабайт трафика, по типу адреса ноды
и стране (`https://discovery.mysterium.network/api/v4/prices`). На 17.09.2026 WireGuard стоит 0.00048 MYST
в час и 1.72 MYST за ГиБ, через домашние адреса — 3.83 MYST за ГиБ; бесплатных нод нет. Перед соединением
нода проверяет, что на балансе хватит хотя бы на минуту и мегабайт по цене предложения.
Бесплатный выход без криптовалюты — Tor ([docs/manuals/torUplink.md](docs/manuals/torUplink.md)).

## Установка

Debian 12/13 или Raspberry Pi OS 64-bit, amd64/arm64:

```bash
curl -fsSL https://raw.githubusercontent.com/borodatych/VibeDPN/main/install.sh | sudo bash
```

До релиза ветка `main` пуста — ставить с `VIBEDPN_BRANCH=next` по
[docs/manuals/installation.md](docs/manuals/installation.md). Скрипт ставит Docker, клонирует репозиторий
в `/opt/vibedpn` и собирает CLI `vibedpn`; дальше — `sudo vibedpn init` (следующий шаг плана).

## Как направить устройства через коробку

Коробка стоит в вашей LAN рядом с обычным роутером и работает шлюзом и DNS для тех устройств,
которые на неё указывают. Адрес коробки в LAN — `network.lan_address` в `config.yaml` (его находит
`vibedpn init`); закрепите его за коробкой на роутере, чтобы он не менялся.

**Одно устройство вручную.** В настройках сети устройства укажите адрес коробки как шлюз
(маршрутизатор) и как DNS-сервер. Остальные устройства продолжают ходить как раньше.

**Вся сеть через роутер.** В DHCP-сервере роутера задайте для клиентов шлюз и DNS равными адресу
коробки — это DHCP-опции 3 (шлюз) и 6 (DNS). В веб-интерфейсах домашних роутеров они обычно
называются «основной шлюз» и «DNS-сервер» в настройках DHCP/LAN. Пример для OpenWrt, где коробка —
`192.168.1.2`:

```bash
uci add_list dhcp.lan.dhcp_option="3,192.168.1.2"
```

```bash
uci add_list dhcp.lan.dhcp_option="6,192.168.1.2"
```

```bash
uci commit dhcp && service dnsmasq restart
```

Устройства получат новые настройки при следующем продлении аренды или переподключении к сети.

**Панель коробки** открывается на устройстве, которое спрашивает DNS у коробки, по адресу
`http://vibedpn.lan` (имя меняется ключом `ui.host_name`), с любого устройства LAN — по
`http://<адрес коробки>`. Вход — паролем, который спросил `vibedpn init`.

**Если в режиме `full` у сети есть IPv6** от роутера провайдера, устройства могут ходить в интернет
по IPv6 мимо коробки: туннели VibeDPN работают по IPv4. AdGuard в `full` не отдаёт AAAA-записи, а
`vibedpn doctor` предупреждает о глобальном IPv6 в LAN — надёжнее выключить IPv6 (RA/DHCPv6) для
LAN на роутере.

## Безопасность коротко

- Веб-интерфейс и API слушают только LAN-интерфейс; на VPS — только через wg-туннель.
- Никакой телеметрии в наш адрес: метрики ноды идут только в Mysterium.
- Секреты (`.env`, ключи WireGuard, keystore ноды) не попадают в git и уезжают в бэкап одним
  файлом.
- **Exit-нода = чужой трафик с вашего IP.** Рекомендация: provider на VPS, дома — только `client`.
